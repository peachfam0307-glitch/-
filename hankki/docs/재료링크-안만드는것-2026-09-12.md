# 🚫 재료 링크를 «안 만드는 것» — 창업자 판정 (2026-09-12)

> 📮 창업자 = *"내가 못넣는다는 것도 다 빼고."*
> ⛔ 여기 적힌 것은 **목록에 다시 올리지 않는다** — 매번 다시 보면 창업자가 또 판단해야 한다.

## 까닭별

| 재료 | 왜 안 만드나 |
|---|---|
| 청주 | **술은 인터넷 판매가 안 된다** |
| 꿀 | 창업자가 안 사 먹어 봐서 추천 못 함 |
| 소고기 | 부위가 너무 많아 하나로 못 고름 |
| 우삼겹 · 차돌박이 · 항정살 | 추천 못 함 |
| 달래 | **제철이 아니라 지금 없다** (제철 오면 다시 본다) |
| 고마다래 소스 | 파는 게 아니다 (레시피에서 만드는 것) |

⭐ 「달래」는 **제철이 오면 되살린다** — 이 표에서 빼면 목록에 다시 오른다.
